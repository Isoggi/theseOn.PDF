# Code of Conduct

We want participation in this project to be welcoming, respectful, and constructive.

## Expected behavior

- Be considerate and respectful in discussions and reviews.
- Critique ideas and code, not people.
- Accept constructive feedback and focus on what is best for the project.
- Respect different experience levels, backgrounds, and viewpoints.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks.
- Insults, threats, or deliberately disruptive behavior.
- Publishing another person's private information without permission.
- Any other conduct that would be inappropriate in a professional community.

## Enforcement

Project maintainers may edit or remove contributions and may restrict participation when necessary to keep the community safe and constructive. Report conduct concerns privately to the repository maintainers through GitHub rather than posting sensitive details publicly.
